## Component Overview

**Category:** Navigation / Layout  
**Primary Use:** Render the authenticated user’s sidebar navigation with links to profile, sessions, blogs, subscriptions, bookings, orders, meal plans, help center, and settings actions.

This component is designed to be **used as-is** across user-facing authenticated pages and is **not intended to be a generic navbar**.

---

## Responsibility Contract

### What this component does

- Renders a vertical (and responsive) navigation bar for logged-in users
- Highlights active sections based on props
- Provides navigation links to all major user areas
- Exposes Settings actions via popover:
  - Log out (confirmation dialog)
  - Delete account (confirmation dialog)
- Handles logout and account deletion side effects

### What this component does NOT do

- Does not manage authentication state globally
- Does not fetch user profile data
- Does not control routing logic outside navigation
- Does not render children or page content

> This is a **layout-level UI component with side effects** limited to logout and account deletion.

Each item:

- Uses `next/link`
- Displays an icon + label
- Applies visual state based on props

---

## Settings Actions (Popover)

### Actions Provided

- **Log Out**

  - Opens confirmation dialog
  - Calls `useLogout()` hook
  - Clears auth cookies
  - Redirects user

- **Delete Account**
  - Opens destructive confirmation dialog
  - Calls delete user API
  - Clears all auth-related cookies
  - Redirects to signup page

---

## Side Effects & Internal Logic

- Reads `user_id` from cookies
- Uses `useRouter` for navigation
- Uses `useLogout` hook for logout handling
- Performs API call for account deletion
- Clears:
  - `access_token`
  - `refresh_token`
  - `id_token`
  - `user_id`
  - `genToken`
  - user metadata cookies

- Fixed vertical layout on desktop
- Collapses to horizontal/top layout on mobile
- Uses Tailwind utility classes
- Icons are inline SVGs for full control

---

## Modification Guidelines

### Safe to modify

- Icons
- Text labels
- Tailwind spacing and typography
- Breakpoints and layout classes

### Do NOT modify

- Cookie cleanup logic
- Logout flow
- Delete account API call
- Confirmation dialogs without updating behavior documentation

---

## Dependencies & Assumptions

- Requires authenticated user (`user_id` cookie present)
- Depends on:

  - `@/components/ui/dialog`
  - `@/components/ui/popover`
  - `useLogout` hook

- Assumes API endpoint is available via env

---

## When to Use / When NOT to Use

### Use when

- Rendering authenticated user pages
- Consistent navigation is required
- User actions like logout/delete are needed

### Do NOT use when

- Public pages
- Admin dashboards
- Stateless or unauthenticated views

## Summary

`UserNavbar` is a **state-aware navigation component** for authenticated users, combining routing, visual state, and critical account actions.
It should be reused without structural modification and controlled via props for active states.
